2. PRODUCT VISION
============================================================

ApplyPilot AI is a Personal AI Career and Job Application SaaS platform.

The product workflow:
DISCOVER -> UNDERSTAND -> MATCH -> IDENTIFY SKILL GAPS -> LEARN -> PREPARE -> APPLY FASTER -> TRACK -> IMPROVE CAREER

Primary Goal: Reduce repetitive application work from 2–3 hours to 10–20 minutes wherever technically, legally, and safely possible while keeping sensitive actions under user control.
